EL PROYECTO

Organizar archivos
es solo el principio.

Facturas, planos, pedidos e informes contienen información útil, pero repartida entre archivos y formatos distintos. Este proyecto plantea un recorrido común para convertirla en datos que se puedan localizar y consultar.

El prototipo combina lectura de PDFs, OCR para imágenes y escaneos, fichas JSON y almacenamiento en SQLite. Las plantillas ayudan con formatos repetitivos; la IA local añade una vía de extracción para textos y estructuras variables.

El original y sus datos,

La interfaz reúne el listado documental, el texto reconocido, los metadatos y el resultado de la extracción mediante IA. Permite revisar qué se ha obtenido y acceder a los archivos asociados.

  • Búsqueda por nombre o contenido

La captura muestra una extracción de IA completada sobre una factura de ejemplo.

02 / PLANTILLAS VISUALES

Cuando el formato se repite,
la extracción se reutiliza.

Para facturas, planos, informes o pedidos recurrentes, las plantillas permiten definir zonas visuales y asociarlas a campos concretos. El objetivo es reutilizar esa configuración en documentos con el mismo formato.

  • Selección de campos documentales
  • Definición de zonas sobre el PDF
  • Guardado de plantillas
  • Aplicación a documentos repetitivos

La captura ilustra el editor; no representa una medición de precisión ni un resultado de extracción por plantilla.

FLUJO DOCUMENTAL

Un recorrido común.
Dos formas de extraer.

La IA complementa el proceso.
El OCR y la base documental funcionan como capas propias.

  1. 01

    Leer el archivo

    PDF, JPG, JPEG, PNG o TIFF. Lectura de texto en PDFs y OCR con Tesseract cuando el contenido es una imagen o un escaneo.

    Texto extraído · TXT
  2. 02

    Crear la ficha

    Metadatos como proyecto, cliente, proveedor, fecha, número y tipo documental, junto con la ruta y el tamaño del archivo.

    Ficha documental · JSON
  3. 03

    Guardar y consultar

    Registro en SQLite para localizar documentos por nombre o contenido, actualizar archivos reprocesados y controlar duplicados.

    Base documental · SQLite
FORMATOS REPETITIVOS

Plantillas por zonas

Definir dónde están los campos permite reutilizar la extracción cuando el diseño del documento se mantiene.

EXTRACCIÓN OPCIONAL

IA ejecutada localmente

Ollama y Qwen2.5 7B interpretan el texto OCR y generan datos estructurados. Pueden ayudar cuando cambian el formato o el orden del texto.

Los datos extraídos requieren revisión: la calidad del escaneo, el OCR y el modelo pueden afectar al resultado.

DECISIONES TÉCNICAS

Cada capa tiene
su función.

Un prototipo de escritorio que combina procesamiento documental, almacenamiento local y una capa opcional de interpretación.

01

Python + Tkinter

Lógica de procesamiento e interfaz de escritorio para trabajar con los documentos y sus datos asociados.

02

PyMuPDF + Tesseract + Pillow

Lectura y visualización de PDFs, reconocimiento de texto y tratamiento de imágenes.

03

SQLite + JSON

Consulta del índice documental y fichas estructuradas asociadas a los archivos.

04

Ollama + Qwen2.5 7B

Extracción avanzada sobre el texto reconocido, con ejecución del modelo en el equipo y sin depender de una API de IA externa para ese flujo.
